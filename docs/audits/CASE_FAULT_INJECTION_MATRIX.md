# CASE - Fault Injection Matrix (A-G)

**Fecha:** 2026-11-11 (consolidación single-consumer)  
**Estado:** **Cubierto en escenarios deterministas controlados (A–G)** dentro del entorno single-consumer soportado (SQLite temporal, 1 proceso, hooks test-only `CASE_TEST_FAULT_INJECTION=1`). No se reclaman garantías distribuidas/multi-proceso ni invariantes exhaustivas en todos los caminos externos.

- **Reservas:** no se verifican invariantes exhaustivas (todos los conteos de eventos por tipo/operación, consistencia completa idempotency↔decision↔audit↔caso en cada variación, multiproceso/segundo reconciliador concurrente, interrupciones reales de SO).
